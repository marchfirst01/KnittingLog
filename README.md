# 뜨개로그 (KnittingLog)

뜨개 프로젝트를 기록하고 친구들과 함께 뜨는(함뜨) React Native 앱입니다. Expo(SDK 57) + Expo Router + TypeScript로 만들었습니다.

## 실행

```bash
npm install
npm start          # Expo Go 앱으로 QR 스캔
npm run ios        # iOS 시뮬레이터
npm run android    # Android 에뮬레이터
npm run web        # 브라우저
npm run typecheck
```

## 데모 계정

처음 실행하면 로그인 화면이 나옵니다. 새로 가입하거나 아래 데모 계정으로 로그인하세요(비밀번호는 모두 `1234`).

`seeun_knits`(세은) · `sungyu_kr`(선규) · `jiyeon_wool`(지연) · `minji.knit` · `sky_yarn` · `doyun_stitch` · `sua_loop`

모든 계정이 한 기기 안에 저장되므로, 로그아웃한 뒤 다른 계정으로 로그인하면 초대·친구 요청이 실제로 오가는 것을 확인할 수 있습니다. 비공개방 코드 검색은 `KNIT42`로 해 볼 수 있습니다.

## 화면

| 경로 | 화면 | 기능 |
| --- | --- | --- |
| `/login`, `/signup` | 로그인 / 회원가입 | 아이디(영문 소문자·숫자·`_` `.`, 4~20자), 닉네임, 비밀번호로 가입(SSO 없음). 비밀번호는 SHA-256 해시로 저장. 로그인하지 않으면 다른 화면에 들어갈 수 없음 |
| `/` | 메인 | **나의 프로젝트**: 작업 중 → 시작 전 → 종료 순, `전체/혼자/함뜨` 필터. **모집 중**: 받은 함뜨 초대(수락/거절), 방 이름·참여 코드 검색, 공개방 목록과 참여 신청 |
| `/mypage` | 마이페이지 | 프로필, 한 줄 소개, 친구 검색·요청·수락·해제, 로그아웃 |
| `/project/[id]` | 뜨개로그 상세 | 타이머와 기록 팝업(글·사진, 날짜·시간 자동 입력), 수동 추가·수정·삭제, 함뜨 멤버별 기록, 반응·댓글. ⚙️ 설정: 혼자/함뜨 전환, 공개/비공개 전환, 참여 코드 공유, 최대 인원·소개, 참여 신청 수락, 친구 초대, 함뜨 나가기 |
| `/project/new` | 새 프로젝트 | 혼자/함뜨, 공개방/비공개방, 친구 초대(초대장 발송), 최대 인원·모집 소개 |

### 함뜨 참여 방법

- **공개방**: '모집 중' 목록에 보임 → 참여 신청 → 방장이 수락
- **비공개방**: 목록에 안 보임 → 6자리 **참여 코드**를 '모집 중' 검색창에 입력하면 바로 참여
- **친구 초대**: 방 멤버가 친구에게 초대를 보냄 → 친구의 '모집 중' 탭 상단 **받은 초대**에서 수락

## 구조

```
src/
  app/            # Expo Router 화면
  components/     # UI 컴포넌트 (카드, 타이머, 기록, 기록 작성 시트 등)
  store/          # 전역 상태 (Context + useReducer, AsyncStorage에 저장)
  data/mock.ts    # 데모 데이터
  theme.ts        # 색상·폰트 토큰
  types.ts
```

현재는 백엔드 없이 기기 안에만 데이터를 저장하는 데모입니다(마이페이지 하단의 **데모 데이터 초기화**로 되돌릴 수 있습니다). 계정도 기기 안에만 있으므로 실제 서비스 전에는 서버 인증으로 바꿔야 합니다. 실제 친구·함뜨 기능을 쓰려면 인증과 서버(예: Supabase, Firebase)를 붙이고 `src/store`의 액션을 API 호출로 바꾸면 됩니다.
