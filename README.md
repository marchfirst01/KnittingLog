# 뜨개로그 (KnittingLog)

뜨개 프로젝트를 기록하고 친구들과 함께 뜨는(함뜨) React Native 앱입니다. Expo(SDK 57) + Expo Router + TypeScript로 만들었습니다.

## 실행

```bash
npm install
npm start          # Expo Go 앱으로 QR 스캔
npm run ios        # iOS 시뮬레이터
npm run android    # Android 에뮬레이터
npm run web        # 브라우저
npm run typecheck
```

## 핵심 개념

- 모든 프로젝트는 한 가지 형태이고 **기본은 비공개**(나만 봄). 친구를 초대해 수락하면 상세 화면 맨 위에 **멤버 아이콘**이 생기고, 누르면 각자의 기록을 볼 수 있습니다.
- **상태·실·기록은 개인 소유**. 상태는 `진행중 / 보관 / 종료`이고, 종료는 프로젝트 종료가 아니라 *내 기록 종료*입니다(작업 기간 자동 표시).
- 멤버가 빠지는 경우

  | 케이스 | 프로젝트 방 | 개인 기록 |
  | --- | --- | --- |
  | 본인이 종료 | 남아 있음 (흑백 + "프로젝트 종료 유저입니다!") | 유지 |
  | 본인이 나가기 | 빠짐 | 혼자 진행하는 프로젝트로 남아 이어서 기록 가능 |
  | 방장이 추방 | 빠짐 | 혼자 진행하는 프로젝트로 남아 이어서 기록 가능 |

- **방장**: 친구 초대(방장만 가능), 멤버 추방, 방장 양도, 이름·대표 사진 수정. 멤버가 있으면 삭제·나가기 불가 → 양도하면 일반 멤버가 되어 나가기 가능. 혼자 남은 프로젝트는 바로 삭제.
- **프로필 공개 범위**: 전체 공개 / 친구 공개 / 비공개. 볼 수 없는 사람에게는 프로필에서 기록과 총 뜨개 시간이 가려집니다(함께 하는 프로젝트 안에서는 보임).
- **신고·차단**: 차단하면 서로의 프로필·게시글·기록이 안 보이고 친구 관계·요청·초대가 끊어집니다. 신고는 기기에 접수만 저장합니다(누적 조치는 서버가 생긴 뒤 운영 정책으로).

## 화면

| 경로 | 화면 | 기능 |
| --- | --- | --- |
| `/login`, `/signup` | 로그인 / 회원가입 | 아이디·닉네임·비밀번호 가입(SSO 없음, 비밀번호는 SHA-256 해시). 약관 링크 |
| `/` | 메인 | **내 프로젝트**: 받은 초대, `전체/진행중/보관/종료` 필터, 카드에 방장·공유 인원·기간(`26.09.10 ~ ing`)·내 상태. **피드**: 작품 자랑 게시글(좋아요·댓글·신고·차단) |
| `/project/[id]` | 프로젝트 상세 | 방장 👑 표시, `…` 메뉴(수정·친구 초대·방장 양도·나가기·삭제), 내 상태 변경. 맨 위 멤버 아이콘으로 각자의 진행상황·기록 전환. 내 기록: 하단 고정 작업바(타이머 + 단수 카운터. 기본은 카운터 2개만 보이고, 손잡이·타이머 영역을 잡고 위로 끌어당기면 전체가 펼쳐짐), 카운터 관리(표시·순서·추가·수정·삭제), 기록 추가. 다른 멤버: 프로필 이동, 친구 추가, 방장의 양도·내보내기 |
| `/project/new` | 새 프로젝트 | 이름·대표 사진·내 실·내 바늘·상태, 친구 초대(선택) |
| `/post/new` | 게시글 쓰기 | 사진·글·내 프로젝트 연결 |
| `/user/[id]` | 프로필 | 기록(공개 프로필만)·게시글, 친구 추가, 신고·차단 |
| `/mypage` | 마이페이지 | 프로필·계정 ID·소개·공개 범위·총 뜨개 시간, 뒤로가기 시 항상 메인으로, 내 기록 모아보기, 차단 목록, 약관 및 정책, 친구 검색·요청, 로그아웃 |
| `/logs` | 내 기록 모아보기 | 프로젝트 구분 없이 시간순, 프로젝트 이름 표시 |
| `/policy` | 약관 및 정책 | 이용약관·개인정보처리방침·커뮤니티 가이드 (초안) |

## 구조

```
src/
  app/            # Expo Router 화면
  components/     # UI 컴포넌트 (카드, 타이머, 기록, 기록 작성 시트 등)
  store/          # 전역 상태 (Context + useReducer, AsyncStorage에 저장)
  data/mock.ts    # 데모 데이터
  theme.ts        # 색상·폰트 토큰
  types.ts
```

현재는 백엔드 없이 기기 안에만 데이터를 저장하는 데모입니다(마이페이지 하단의 **데모 데이터 초기화**로 되돌릴 수 있습니다). 계정도 기기 안에만 있으므로 실제 서비스 전에는 서버 인증으로 바꿔야 합니다. 실제 친구·함뜨 기능을 쓰려면 인증과 서버(예: Supabase, Firebase)를 붙이고 `src/store`의 액션을 API 호출로 바꾸면 됩니다.
