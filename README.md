# 뜨개로그 (KnittingLog)

뜨개 프로젝트를 기록하고 친구들과 함께 뜨는(함뜨) React Native 앱입니다. Expo(SDK 57) + Expo Router + TypeScript로 만들었습니다.

## 실행

```bash
npm install
npm start          # Expo Go 앱으로 QR 스캔
npm run ios        # iOS 시뮬레이터
npm run android    # Android 에뮬레이터
npm run web        # 브라우저
npm run typecheck
```

## 화면

| 경로 | 화면 | 기능 |
| --- | --- | --- |
| `/` | 메인 | **나의 프로젝트**: 작업 중 → 시작 전 → 종료 순으로 정렬, `전체/혼자/함뜨` 필터. **모집 중**: 다른 사람이 공개로 연 함뜨 목록과 참여 신청/취소. 우측 상단 아바타를 누르면 마이페이지로 이동 |
| `/mypage` | 마이페이지 | 프로필, 한 줄 소개 수정, 닉네임·핸들 검색 후 친구 요청, 친구 목록과 친구 해제, 받은/보낸 친구 요청 수락·거절·취소 |
| `/project/[id]` | 뜨개로그 상세 | 타이머(시작/일시정지/종료). 종료하면 기록 작성 팝업이 뜸(글 2~3줄, 사진 1장, 날짜·시간·소요 시간은 자동 입력, 기록하지 않기도 가능). 수동 기록 추가, 내 기록 수정·삭제. 함뜨라면 멤버 아이콘으로 친구 기록 보기, 이모지 반응과 댓글. 방장은 멤버 관리와 참여 신청 수락, 공개 모집 켜기/끄기 가능 |
| `/project/new` | 새 프로젝트 | 이름·실·바늘·대표 사진, 혼자/함뜨, 친구 초대, 공개 모집(최대 인원, 소개) |

## 구조

```
src/
  app/            # Expo Router 화면
  components/     # UI 컴포넌트 (카드, 타이머, 기록, 기록 작성 시트 등)
  store/          # 전역 상태 (Context + useReducer, AsyncStorage에 저장)
  data/mock.ts    # 데모 데이터
  theme.ts        # 색상·폰트 토큰
  types.ts
```

현재는 백엔드 없이 기기 안에만 데이터를 저장하는 데모입니다(마이페이지 하단의 **데모 데이터 초기화**로 되돌릴 수 있습니다). 실제 친구·함뜨 기능을 쓰려면 인증과 서버(예: Supabase, Firebase)를 붙이고 `src/store`의 액션을 API 호출로 바꾸면 됩니다.
